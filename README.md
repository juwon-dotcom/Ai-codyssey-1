# ia-codyssey
Github와 Codyssey를 연동하기 위해 만들어진 Repository입니다.

# 용어 설명
## pwd	현재 내 위치 확인	Print Working Directory (작업 폴더 출력)
## ls -a	목록 보기(숨김 파일 포함)	List (목록), -a = all(전부)
## cd	폴더 이동	Change Directory (폴더 변경)
## mkdir	폴더 만들기	Make Directory
## cp	복사	Copy
## mv	이동/이름변경	Move
## rm	삭제	Remove
## cat	파일 내용 보기	concatenate (이어붙여 출력)
## touch	빈 파일 생성	"건드리다" → 파일 생성/시간 갱신
